# MCP (Model Context Providers)

## What MCP is and What its not

- Easy way to use tools written by someone else
- Easy way to share your tools with others
- Easy way to connect LLMs with tools.
- The game-changer is the ADOPTION.

What its not

- Its the interface, not the tools themselves
- Its an agreed standard, not major innovation
- its not efficient - overuse can fill up the context window and lead to poor results, even with recent context use improvements.

## MCP Technicalities

MCP Host: The application which is running and needs to call tools.

MCP Client: Code that runs withing the MCP host 

MCP Server: The tools written by someone else.
