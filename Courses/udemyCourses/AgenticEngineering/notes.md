# AI Coder: Complete Claude Code & Coding Agents

## Terminology

- Vibe coder : Amature prompt engineers.
- Vibe engineer : Prompt engineers with SE background.
- Agentic Coder : Someone who builds agents.

## Setting the Scene

There are 3 interfaces to writing software with Agents.

- IDE
    
    Cursor, codex, antigravity, windsurf

- Plugin

    Github copilot, Claude code extentsion for VS code, cline

- CLI

    Claude Code, Cursor CLI, Codex CLI, Gemini CLI, OpenCode, Amp


## Evolution of the programmer in 2024-2026 by Steve Yegge

Stage 1:

   ChatGPT, AI auto-complete.

Stage 2: 

    Coding Gent in IDE sidebar, asks for permissions before changes.

Stage 3:

    Coding agent in IDE sidebar, YOLO mode.

Stage 4:

    Coding agent in IDE main window, YOLO mode, check diffs

Stage 5: 

    Coding agent in CLI, YOLO, diffs scroll by

Stage 6: 

    Multi agent in CLI, 3-5 agents

Stage 7:

    10+ agents in CLI manually managed. Agents and sub agents doing work for you.

Stage 8:

    Agents orchestrate agents
