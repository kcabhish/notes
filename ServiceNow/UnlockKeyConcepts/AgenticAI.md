# How Does AI Learn?

- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

## Supervised Learning

- Supervised learning is a machine learning method in which AI models are trained on labeled data—that is, data with known inputs and correct outputs. By analyzing these input-output pairs, the model learns patterns to accurately predict outcomes for new, unseen data.

You could think of supervised learning as similar to using flashcards to train the AI.

## Unsupervised Learning

- Unsupervised learning is a machine learning technique that utilizes unlabeled data sets for training. In this approach, a model does not have predefined guidelines for expected outputs or relationships. Instead, the objective is to explore the data and uncover patterns, trends, and relationships without human intervention.

Unlike supervised learning, where there are “right” or “wrong” answers, unsupervised learning seeks to analyze and cluster unlabeled data sets. This analysis includes:

- Associating data points by common traits

- Establishing relationships between data points

- Identifying outlier data points and removing them

This data analysis resembles how you'd solve a puzzle.

## Reinforcement Learning

Reinforcement learning is a machine learning method where the AI learns through trial and error. As it works in its environment, rewards and penalties are used to reinforce helpful actions and ignore unhelpful ones, allowing the system to discover the best way to reach a goal on its own, without guidance from a human. This is well-suited for AI agents, as they are specifically designed to take action.

This is similar to any sport or game in which points are awarded, and penalties are given depending on the player's actions.
