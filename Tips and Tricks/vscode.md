# VSCODE TIPS AND TRICKS

## Setting up `code .`

On windows it should come in by default. For Mac:

- Launch Visual Studio Code.
- Open the Command Palette by pressing Cmd + Shift + P.
- Type shell command into the search box.Click on Shell Command: Install 'code' command in PATH.Choose install code in PATH, and hit return. You'll be asked to allow osascript to make changes to PATH. Enter your password or use TouchID to give permission. [r/vscode].
- Restart your terminal for the changes to take effect
